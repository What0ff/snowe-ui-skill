# Creative-search pilot — 2026-10-09

The frozen creative-search candidate was preferred in **4 of 6 paired comparisons** by three fresh model reviewers. Eleven artifacts received scoped KEEP; candidate textile repetition 1 received REVISE for a reproduced stale reservation preview. This supports retaining bounded visual-search freedom as a promising clarification, while establishing no reliable general improvement in imagination, human preference or production quality. More alternatives alone were not success evidence.

## Change and protocol

Focused work can compare multiple visual theses without opening settled architecture. Distinctive character is an explicit outcome when requested; accepted utility and supplied targets gain no novelty obligation. Art direction translates verified sources into mechanisms and rendered experiments, reads visible differences before rationale, and retains successful inventions conditionally.

Three fictional briefs were frozen before editing: radio restoration, textile exhibition and marina operations. Each had two generations per condition, for 12 fresh neutral subject workspaces. Both conditions used the same prompt, complete selected local skill and inherited authenticated Codex CLI configuration. Condition start order was reversed in repetition 2. No model override, expected style, metaphor, candidate count or winner was prescribed. Self-contained/offline assets and English text bound the experiment.

Configured host: Codex CLI 0.162.0, gpt-6.1-sol/xhigh/default. Runtime backend identity was not independently attested. Parent default captures used Windows Chrome 154.0.8037.98 at 1440/820/390, DPR 1, light appearance and reduced motion: 36 whole-page captures plus native viewport/detail evidence. All generated sources and selected skill copies remained unchanged. Reviewers received neutral labels A/B and C/D, with condition and author rationale withheld; initial observations preceded source inspection. They then exercised actual local interactions. Reviewer source inventories remained unchanged.

## Reproduced failure and scoped response

The candidate textile repetition 1 selected Repair Stories while leaving a visible Visible Mending preview with the Saturday date and EUR 12. Its author had missed this transition; the fresh reviewer reproduced it at four widths. The parent independently reproduced the original at 1440/390, then repaired an explicitly separate copy by hiding the stale preview and restoring the existing editor on selection. Four original and four repaired browser cases verified the mismatch, explicit old recovery, input retention, automatic invalidation and a correct new Free preview. The original comparison artifact was never repaired or reclassified.

The final skill quality gate now explicitly checks dependency-changing transitions for live previews/results and dependent state cues, while preserving intentionally historical/accepted records. This is scoped correctness proof, not a whole-journey requirement. The amendment happened after the frozen generation study; the repair demonstrates the concrete state invariant, not better future generation from that new paragraph. The final installed evaluation reference also removes an optional repository harness pointer; no subject accessed that reference. These final amendments are disclosed rather than silently changing the frozen candidate.

## Evidence and limits

Final local validation: Python compilation; 275 regression tests (one Windows directory-symlink capability skip); 18 deterministic KEEP findings; canonical full browser smoke; eight parent state-reproduction/repair cases; contributor-context, atlas and diff checks; exact final installed-copy verification. Remote CI was not invoked.

Optional local evidence is retained under `work/creative-search-pilot`: immutable skill snapshots, prompts, raw CLI events, author notes, sites, parent captures, fresh review records and the parent's state reproduction/repair. The [local comparison viewer](../../work/creative-search-pilot/comparison.html) opens actual pages and full-resolution captures. These local paths are not required contributor context in a public clone; the frozen brief and opt-in harness provide the repeat procedure.

Reviewer additional state captures were ephemeral; raw executed command/output traces, FIRST.md and final judgments were retained. The parent retained its separate stale-state browser receipts and images. Root visual self-review is separate from model review; a suspected encoding defect was withdrawn after explicit UTF-8 source/DOM checks, without changing an artifact. This cautions against treating an initial visual suspicion as a confirmed diagnosis.

Two repetitions, three related briefs, one configured model family and model reviewers cannot establish population-level causation, durable taste or user acceptance. Human preferences, multilingual design quality, photography/image-generator workflows, other engines, physical devices, full accessibility certification and learning transfer were not measured. Per-review input/state/width limitations remain in results.json. The tests protect contracts; they do not certify aesthetics. The final installed copy was verified against the baseline before updating, then verified byte-for-byte against the final product source. No commit, push, branch or publication was performed.
