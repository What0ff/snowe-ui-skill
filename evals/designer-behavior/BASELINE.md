# Pre-change Behavior Baseline

The same six briefs were run through the former deterministic generator before replacement. All baseline runtime tests passed, but the design behavior exposed catalog anchoring:

| Brief | Former selected result | Observed failure |
|---|---|---|
| Independent bicycle retailer | `Automotive/Car Dealership` + `AI Personalization Landing` | Product analogy became identity and page architecture. |
| Municipal permit service | `Video-First Hero` | A conversion recipe displaced the whole service journey. |
| Pediatric care app | `Task-First Mobile` | Direction was plausible but still selected from the same fixed shell mechanism. |
| Literary magazine platform | `Focused Task Flow` | Raw substring matching treated `platform` as `form`. |
| Warehouse operations | `Operations Workspace` | Best baseline match, but still a predetermined shell rather than synthesized object/task architecture. |
| Experimental musician shop | `Webinar Registration` | Lexical retrieval overrode product and brand context. |

Across all six outputs the generator selected one product row, reasoning recipe, style, palette, font pairing, and landing pattern before emitting an exploration narrative. It exposed no first-class navigation model, content/object model, imagery decision, responsive transformation, or evaluation record.

The current runner must not recreate those selections. Visual and UX improvement is evaluated separately through complete implemented benchmarks.
