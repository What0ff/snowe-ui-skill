# Bounded paired host observation

Four fresh worker agents in two paired rounds received the same Russian request
and a separate standalone Snowe snapshot. None received the root conversation, screenshots,
diagnosis, patch description or expected answer. The request asked for a small
publication-channel screen with a captioned search field, state filter, connect
action, Telegram/GitHub connections and a preference for custom pictograms;
it also asked for a 16/20 px symbol beside “Расстояние между креплениями”.

All inherited the same parent model/reasoning configuration without overrides
and had the same available tools. Actual runtime model identity/token totals
were not independently observed. Control was dispatched first, order was not
randomized, and snapshot directory names exposed control/candidate roles.
Round two added the same bounded stop guidance to both versions. This was not
a fully blinded or statistically controlled experiment.

## Independent repeat

Control repeat again drew service proxies: a paper plane and branch glyph
beside the external names, explicitly described as nonofficial in its source
record. Coordinator source-fidelity disposition is REVISE despite its overall
self-review KEEP. It repaired crowded 16 px arrow joins and muted contrast,
then captured eleven current cases; source/plan/render hashes were checked.

Candidate repeat again retained unchanged owner-provided Telegram/GitHub marks,
including an official white GitHub variant for dark forced colors. It retained
its own labeled 16/20 mounting-span glyphs and ruler/text comparisons. Native
host metrics recorded desktop search/select/connect at top 308, bottom 352 and
height 44 CSS px. Root inspection found coherent desktop/narrow relationships
and clear external identities. There is no reusable visual receipt for this
run; its metrics/source/image bindings and self-review remain separate claims.

Across these two rounds, both control outputs substituted category glyphs and
both candidate outputs used imported identities. That is a bounded observed
source-choice difference. Both versions already made coherent layouts and
useful custom symbols, including actual repairs; generation or alignment
superiority is not established. Two rounds with nonrandom order and differing
proof choices are too small for reliable model-variance, causation or
generalization estimates. User acceptance remains UNCONFIRMED.
