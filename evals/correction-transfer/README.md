# Scoped Correction and Icon-Backing Proof

This authored fictional fixture tests a concrete acceptance boundary: a user-rejected surface behind passive icons must not survive as a renamed class, pseudo-element, rounded square, or below-the-fold repeat. The same request preserves rounded controls and explicitly approves a circular brand mark. It is not a general ban on pills, circles, color or custom icons.

## Reproduce

```text
node scripts/browser-smoke.mjs --capture-correction-transfer
python -m unittest tests.test_visual_acceptance -v
```
