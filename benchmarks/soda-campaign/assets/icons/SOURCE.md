# Doppler control glyphs

Original editable geometric drawings for the campaign controls: one open diagonal arrow, a balanced plus/minus pair and a three-line menu. Preserve familiar action meaning. Native masks use 18 px for navigation/CTA and 16 px for quantity editing; the host supplies labels and focus. Compare actual owner and native crop before acceptance. The open counters and common 2-unit stroke belong to this family; no button geometry is enlarged to fit the draft.

The close glyph uses the same stroke and open diagonal construction in a 44px modal hit region, with an 18px painted slot. It preserves the familiar dismissal meaning.
