# Security Policy

## Supported version

Security fixes are applied to the latest state of the `main` branch. The
project does not currently maintain parallel release branches.

## Reporting a vulnerability

Do not open a public issue for an unpatched vulnerability, credential leak, or
other sensitive report. Use GitHub's **Security → Report a vulnerability** flow
for this repository.

Include:

- the affected file and behavior;
- reproduction steps or a minimal proof of concept;
- the expected security property;
- the realistic impact and prerequisites;
- any suggested mitigation, if known.

You should receive an acknowledgement within seven days. Status updates will
be provided as investigation and remediation progress.

For non-sensitive hardening suggestions, open a regular GitHub issue.
