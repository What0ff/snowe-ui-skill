## Motion and the user-found detail failure

The first rebuild retained rotation/fizz but lost expressive establishment. User feedback reopened that weakness. Current choreography reveals the wordmark, staggers the proposition and releases the product into its settled pose. Flavor transitions connect label, stage color and wave response; pointer response stays with the scene; visible lower-section content receives limited movement. Motion is finite, interruptible and separate from the authored reduced/static equivalent.

The user then identified a white lid artifact that the implementer had missed. The previous flat lid lived outside the 3D cylinder and its apparent attachment check could pass while the material join looked wrong. The correction places one top plane inside the same rigid object, with its rotation and projection, and removes the independently placed overlay. This reopens visual acceptance of the product until native joint details, representative rotation phases and collateral composition are inspected. A one-layer count or bounding-box PASS cannot certify material quality.

The portable plan now requires both whole composition and owner/detail crops. The repository injection probe checks a detached plane, extra painted layer, broken label mask, shrunken icon host and covered flavor label, restoring each before a clean capture. These targeted construction/visibility checks do not claim to find every possible visual artifact.

Further detail review rejected a first rigid-plane repair: its top was occluded at the old perspective angle, and a later visible plane exposed a diameter mismatch. The mesh builder had used the rotated screen-space bounding box while the lid used local CSS dimensions. The final construction derives radius/label height from local resolved CSS size and uses a coherent camera/object tilt. The probe additionally checks local cylinder radius and actual metallic paint survival. The rejected crop remains in review history; structural correctness alone did not close this repair.

## Custom control family

Five original editable SVG masks replace font-dependent control marks: open diagonal arrow, plus, minus, menu and close. They preserve familiar action meaning. CTA/navigation/close slots use 18 px; quantity slots use 16 px. The 24-unit construction uses a common 2-unit stroke, open negative spaces and restrained round terminals, with native owner/detail review rather than an enlarged drawing-sheet claim. Labels, target boxes, state and focus stay with the controls. Exact metadata/source/license bindings live beside the glyphs. No library package is added.
